🚀 Настройка CloudPub

Чтобы ученики могли подключаться через интернет (а не только в вашей сети), нужен аккаунт CloudPub — это бесплатный сервис для публикации локальных приложений.

📖 Как зарегистрироваться (3 минуты):
  1. Откройте cloudpub.ru в браузере
  2. Нажмите «Регистрация» в правом верхнем углу
  3. Введите email и придумайте пароль
  4. Подтвердите email (письмо придёт на почту)
  5. Вернитесь сюда и введите те же email и пароль ниже

⚠️ Если вы используете Lumen только в классе (все ученики в одной Wi-Fi с вами), можно нажать «Пропустить» — CloudPub не обязателен.

🚀 Быстрый старт

  1. Установите Lumen (двойной клик по Lumen Setup 1.1.0.exe)
  2. Запустите приложение с рабочего стола
  3. При первом запуске введите email и пароль CloudPub
  4. Готово! Можно проводить урок

📖 Регистрация в CloudPub

Зачем нужен CloudPub: чтобы ученики могли подключаться к вашему уроку через интернет (с домашнего компьютера, телефона из любой сети), а не только из класса.

Если работаете только в классе (все ученики в одной Wi-Fi с вами) — CloudPub не обязателен. Нажмите «Пропустить».

Пошагово:

  1. Откройте в браузере cloudpub.ru
  2. Нажмите «Регистрация» в правом верхнем углу
  3. Введите email и придумайте пароль (минимум 8 символов)
  4. Согласитесь с условиями и нажмите «Зарегистрироваться»
  5. Проверьте почту — придёт письмо. Нажмите «Подтвердить email» в письме (если письма нет — проверьте папку «Спам»)
  6. Вернитесь в Lumen
  7. В окне «Настройка CloudPub» введите те же email и пароль
  8. Нажмите «Войти»

✅ Если всё правильно — увидите сообщение «Успешно! Можно закрыть окно».

🎓 Как провести урок

Подготовка (за день до урока)

  1. Материалы → ➕ Создать материал
  2. Введите название (например, «Теорема Пифагора, 8А»)
  3. Добавьте теорию (заметки, картинки, файлы) — опционально
  4. Добавьте вопросы (кнопки / текст / квиз) — что будете задавать классу
  5. Сохраните

Создание класса (один раз)

  1. Классы → ➕ Создать класс
  2. Название: «8А»
  3. ➕ Добавить учеников → вставьте список имён (по одному в строке)
  4. Сохраните

На уроке

  1. Откройте 🎛️ Урок
  2. Выберите класс (например, 8А)
  3. Выберите материал (например, «Теорема Пифагора»)
  4. Нажмите ▶️ Запустить приложение
  5. Через 5-7 секунд появится ссылка — отправьте её ученикам или покажите QR-код
  6. Нажмите 📊 Панель учителя — откроется окно управления

Во время урока

  • В панели учителя нажмите на вопрос в списке → ▶️ Задать классу
  • Ученики видят вопрос и жмут одну из трёх кнопок: ✅ Понял / 🤔 Почти / 💥 Потерялся
  • Вы видите карту класса — кто загорелся зелёным, кто красным
  • Внизу — подсказки, как переобъяснить материал

🔧 Решение проблем

«Flask не запустился»

  • Закройте Lumen, откройте заново
  • Если не помогает — переустановите приложение

Ученики не могут зайти по ссылке

Если ученики в классе (в одной Wi-Fi с вами): используйте QR-код или локальный IP.

Если ученики из дома: проверьте, что CloudPub настроен: Настройки → Управление CloudPub → должно быть «✅ Авторизован». Если «⚠️ Не авторизован» — войдите через CloudPub.

Забыли пароль CloudPub

  1. Откройте cloudpub.ru
  2. Нажмите «Войти» → «Забыли пароль?»
  3. Введите email — придёт письмо для сброса
  4. Создайте новый пароль
  5. В Lumen: Настройки → Управление CloudPub → Выйти → войдите с новым паролем

Ученик не может зайти

  • Проверьте, что он ввёл Фамилию Имя через пробел (не просто имя)
  • Проверьте код комнаты или ссылку
  • Если он не в классе, а из дома — CloudPub должен быть настроен
