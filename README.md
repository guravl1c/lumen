# Lumen

**Illuminate understanding** — инструмент формирующего оценивания для учителей.

## Что это

Lumen — веб-приложение для учителя, которое помогает:
- Вести урок на **интерактивной доске** (рисуй, пиши, показывай ученикам в реальном времени).
- **Говорить с классом** через аудиотрансляцию (WebRTC).
- Показывать **транскрипцию речи** (Vosk) — ученики могут читать, если не слышат.
- Задавать **вопросы** и видеть ответы класса в реальном времени.
- Использовать **теорию**, **реакции**, **квизы**.

## Технологии

- **Electron** — оболочка учителя.
- **Flask + SocketIO** — сервер урока.
- **SQLite** — база данных.
- **mediasoup (WebRTC)** — аудио.
- **Vosk** — распознавание речи.

## Установка

1. Скачай `Lumen Setup 2.0.0.exe` из [Releases](https://github.com/guravl1c/lumen-desktop/releases).
2. Запусти установщик.
3. Выбери папку установки.
4. Готово — ярлык появится на рабочем столе.

## Использование

1. Открой **Lumen**.
2. Выбери **класс** и **материал**.
3. Нажми **«Запустить приложение»**.
4. Открой **«Панель учителя»** — начнётся урок.
5. Ученики подключаются по **ссылке-приглашению** или **QR-коду**.

## Что нового в v2.0.0

- **Доска** — учитель рисует, ученики видят в реальном времени.
- **Аудио** — голос учителя транслируется классу (WebRTC).
- **Транскрипция** — ученики могут включить текст речи учителя.
- **Картинки** — вставка изображений на доску и в теорию.
- **Выделение и перемещение** объектов на доске.
