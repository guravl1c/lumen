# Lumen

**Освещаем понимание**

Lumen — приложение для формирующего оценивания в реальном времени. Учитель задаёт вопрос — ученики отвечают с телефона. Учитель сразу видит, кто понял, кто — нет.

## Что это

**Lumen** решает проблему обратной связи на онлайн-уроках:

- Учитель задаёт вопрос — в ответ тишина.
- Ученики боятся отвечать публично.
- Непонятно, кто понял, кто — нет.

**Lumen** даёт:
- Ученикам — ответить одним нажатием.
- Учителю — карту класса в реальном времени.
- Анонимные ответы и вопросы.

## Техническая база

| Компонент | Технология |
|---|---|
| Приложение учителя | Electron |
| Сервер урока | Python + Flask |
| Мгновенная связь | Socket.IO |
| База данных | SQLite |
| Страница ученика | HTML / CSS / JS |
| Туннель | CloudPub |

## Как запустить

**Для учителя:**

1. Скачать установщик из GitHub Releases.
2. Установить.
3. Запустить.

**Для учеников:**

1. Получить ссылку или QR-код.
2. Открыть в браузере на телефоне.
3. Ввести имя — и готово.
